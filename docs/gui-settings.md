# GUI 设置

启动示例：

```powershell
log-reviewer
# 显式切换到文件选择模式
log-reviewer gui --show-file-picker
```

共有三个独立入口，任意时候都保留“上传文件”，另两个入口互斥：

| 入口 | 文件位置 | 行为 |
| --- | --- | --- |
| 上传文件 | 浏览器所在机器 | 上传到部署机器的会话缓存，再读取分析；支持多文件和目录 |
| 选择文件 | 部署机器 | 浏览部署账户有权限访问的文件或目录，直接只读分析 |
| 选择路径 | 部署机器 | 输入文件、目录或通配符路径，校验后直接只读分析 |

Windows 双击程序或无参数启动时，显示“上传文件”和“选择路径”。点击“选择路径”展开输入区。

`--show-file-picker` 默认 `false`；显式启用后显示“选择文件”，隐藏“选择路径”。`--show-path-input=false` 同样切换到文件选择模式。两个参数同时为 `true` 时，“选择文件”优先，仍只显示一个部署文件入口。这些参数永远不隐藏“上传文件”，只控制界面，不替代 API 授权或操作系统文件权限。

所有入口统一按 SHA-256 内容去重，同内容即使名称不同也不会重复加入分析列表；重复上传复用已有缓存文件。同名不同内容仍提供覆盖、保留并重命名或取消选择。完整内容去重需要读取文件内容；上传入口在部署机器收到文件后完成校验。

顶部依次显示“分析主机”“会话验证”和“设置”。会话 token 验证使用独立弹窗。设置包含三个页签，各自保存，标题和页签固定，内容可在小屏幕内滚动：

- 访问控制：允许的客户端 IP / CIDR。
- 文件与分析：远程文件保存目录、所有来源通用的文件名通配符，以及是否包含 INFO / DEBUG / TRACE。
- 识别规则：按语言查看、编辑、保存、恢复内置规则，以及新增或删除自定义语言。

上传文件和粘贴文本与远程下载统一使用配置的保存目录，在会话子目录中隔离保存。修改目录会迁移当前会话文件并更新分析报告路径；新上传使用新目录。本机路径来源保持只读，不迁移源文件。

识别格式使用文件名通配符，例如 `*.log`、`*.log.*`、`*.txt`；每行一条。格式约束本地文件和目录、浏览器上传及远程预览、下载和直接读取。远程获取中的筛选条件进一步缩小选择范围。修改格式不会删除已经保存的文件。

“分析主机”显示运行 Log Reviewer 的主机名。浏览器可能位于另一台机器；日志分析在工具主机执行，不调用云端分析服务。远程直接读取仍会通过 SFTP 将内容传输给工具主机。

输入路径和 Windows 系统选择器均以工具运行账户的权限读取文件。输入路径不弹出系统文件浏览窗口，但并不天然获得更小的文件访问权限。需要限制访问时，应使用专用低权限账户、目录权限和客户端 IP 白名单，并保护会话 token。

文件选择模式下，Windows 本机直连可使用系统选择器；远程浏览器和其他平台使用部署机器网页文件浏览器，支持切换磁盘、目录导航与多选。“上传文件”始终只处理浏览器本机文件，不受此模式影响。拖入页面的文件按上传处理。
