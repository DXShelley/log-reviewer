# GUI 设置

启动示例：

```powershell
log-reviewer gui --show-file-picker=false --show-path-input=true
```

`--show-file-picker` 默认 `true`，控制“选择文件”按钮；`--show-path-input` 默认 `false`，控制“输入路径”按钮。两个参数可以独立设置，只控制界面显示，不替代 API 授权或操作系统文件权限。

顶部“设置”包含两组，分别保存：

- 访问控制：会话 token 验证、允许的客户端 IP / CIDR。
- 文件与分析：远程文件保存目录、所有来源通用的文件名通配符，以及是否包含 INFO / DEBUG / TRACE。

识别格式使用文件名通配符，例如 `*.log`、`*.log.*`、`*.txt`；每行一条。格式约束本地文件和目录、浏览器上传及远程预览、下载和直接读取。远程获取中的筛选条件进一步缩小选择范围。修改格式不会删除已经保存的文件。

“分析主机”显示运行 Log Reviewer 的主机名。浏览器可能位于另一台机器；日志分析在工具主机执行，不调用云端分析服务。远程直接读取仍会通过 SFTP 将内容传输给工具主机。

输入路径和 Windows 系统选择器均以工具运行账户的权限读取文件。输入路径不弹出系统文件浏览窗口，但并不天然获得更小的文件访问权限。需要限制访问时，应使用专用低权限账户、目录权限和客户端 IP 白名单，并保护会话 token。

非 Windows 平台或远程浏览器通过浏览器选择和上传文件；Windows 本机直连可使用系统选择器。隐藏输入路径时不会自动打开路径输入区域。
