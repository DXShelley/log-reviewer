# SFTP 远程日志获取

v0.6.0 支持 `--ssh-dir` 和 GUI 的“.ssh 目录”设置。未传主机指纹或 `known_hosts` 时自动加载此目录下的 `known_hosts`；目录省略时使用运行账户的 `~/.ssh`。GUI 路径属于工具所在机器。端口默认 22，详细示例见 [工作区说明](workspace-usage.md)。

GUI 按需连接远程服务器的单个文件或目录，默认通过只读 SFTP 文件句柄直接分析、查询详情和导出，不预先下载源日志。仅网络断线或超时等读取错误触发重新连接，将对应文件缓存到工具工作目录后继续读取；认证、权限和文件变化错误不会触发复制。源文件始终只读，工具仍会在本地保存分析索引和报告。内置 `github.com/pkg/sftp` 与 `golang.org/x/crypto/ssh`，无需安装 OpenSSH 客户端或额外动态库。

直接读取期间凭据只保存在进程内存中，关闭工具后释放，不写入报告或状态文件。已加入的远程源需要在本次工具运行期间保持可连接；重新启动后打开导出的 JSON 报告，需重新连接并分析才能查看远程详情。CLI `fetch --analyze` 同样直接读取，报告详情重新查看时需要重新连接；不带 `--analyze` 的 `fetch` 和旧 API `download` 为显式下载入口，保留下载语义。

## GUI

点击“远程获取”，填写服务器、SSH 端口、用户名、主机 SHA256 指纹及远程路径。选择密码或私钥认证；私钥支持选择本机文件或粘贴，支持加密私钥口令。

目录过滤每行一条，默认三条规则为 `*.log`、`*.log.*`、`*.txt`；文件名规则任一匹配即进入预览，可以包含子目录。明确指定单个文件时不使用文件名过滤。点击“连接并预览”后展示匹配文件的路径、大小和修改时间，此时不下载文件；默认全选，可使用路径筛选、全选、反选、清空、重置，再点击“获取所选文件”。选择上限按最多文件数和总大小限制检查。默认不勾选“获取后分析”，获取成功后可手动开始分析。失败不会把不完整文件加入分析。密码和私钥口令均支持小眼睛切换显隐。

通配符示例：`app-*.log` 匹配 app- 开头的日志。以 `regex:` 开头的规则使用 Go 正则，例 `regex:^app-\d{4}-\d{2}-\d{2}\.log$` 匹配 app-2026-10-15.log，`regex:(?i)\.(log|txt)$` 忽略大小写匹配日志或文本后缀。正则默认匹配文件名中的任意位置，需要完整匹配时加 `^` 和 `$`；不支持前后查找和反向引用。仍兼容逗号分隔的通配符，正则中的逗号保持原样。过滤框下有可展开的说明与示例。

可以填写预先核实的指纹，或使用工具所在机器的 known_hosts。首次连接未知主机时会显示服务器指纹，核实后点击“已核实，使用此指纹”，自动沿用本次填写的密码或私钥重新连接，无需再次输入。请从服务器管理员或已可信的连接核实，例如在服务器检查实际启用的 host key：

```bash
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256
```

指纹应对应服务器实际协商使用的主机密钥类型。指纹不匹配时获取失败，不提供跳过验证选项。新服务器或轮换主机密钥，需要独立核实后再更新指纹。

成功连接并完成预览后，主机信息自动保存到 `--state-file` 指定的状态文件，默认与可执行文件同目录的 `log-reviewer-state.json`，保留最近 20 条，按服务器、端口、用户名和认证方式去重。下次打开“远程获取”，可从“已连接主机”回填服务器、端口、用户名、认证方式、指纹、路径和过滤设置。状态文件同时保留访问控制配置。密码、私钥内容和私钥口令均不落盘。

预览会话将认证信息暂存在服务端内存中，15 分钟后失效；取消、关闭窗口或替换预览时释放尚未加入的预览。加入的远程源为后续只读分析保留内存中的凭据，直到工具关闭。关闭窗口也会取消仍在运行的预览或获取任务。获取会重新连接并校验预览时的主机指纹，只接受预览中的勾选项；文件大小或修改时间变化时需重新预览。浏览器只在等待首次指纹确认时暂存认证信息，关闭对话框会丢弃待确认信息。远程 API 请求 30 秒超时，连续三次状态查询失败后停止轮询并恢复操作，可重新连接。

## 忽略目录

远程路径支持每行一个文件或目录，例如同时填写 `/var/log/myapp` 和 `/opt/service/logs`。所有路径使用同一组过滤与递归设置，最终匹配列表统一勾选加入只读分析，文件数和大小限制按合计计算。重复路径及父子目录重叠产生的相同文件路径只列出一次。任一路径读取失败时会提示对应路径，修正后重新预览。所有配置位于匹配文件列表之前。

递归获取时忽略目录：在过滤框中每行填写一条规则。例如以下配置获取 `.log` 文件，并跳过各层级中名为 `backup` 或以 `cache` 开头的目录及其全部内容：

```text
*.log
exclude-dir:backup
exclude-dir:cache*
```

`exclude-dir:` 后填写目录名通配符，不含路径分隔符；需要勾选“包含子目录”，不排除明确填写的入口目录。

## CLI

获取单文件，使用私钥并指定已核实的指纹：

```bash
./log-reviewer-linux-amd64 fetch \
  --host 192.168.1.20 --port 22 --user logreader \
  --path /var/log/myapp/app.log --key ~/.ssh/id_ed25519 \
  --fingerprint 'SHA256:<已核实的主机指纹>' --out-dir ./remote-logs
```

获取目录并分析，使用已有 OpenSSH known_hosts：

```bash
./log-reviewer-linux-amd64 fetch \
  --host 192.168.1.20 --user logreader --path /var/log/myapp \
  --key ~/.ssh/id_ed25519 --known-hosts ~/.ssh/known_hosts \
  --pattern '*.log,*.txt' --recursive --max-files 1000 \
  --max-bytes 10737418240 --out-dir ./remote-logs --analyze
```

不指定指纹或 known_hosts 时，CLI 尝试 `~/.ssh/known_hosts`，不存在、未知主机或密钥变化都拒绝连接。指纹与 known_hosts 同时提供时使用指纹。

Windows 密码认证：

```powershell
# 交互输入，不把密码放进命令参数或历史。
$credential = Get-Credential -UserName logreader
$env:LOG_REVIEWER_SFTP_PASSWORD = $credential.GetNetworkCredential().Password
try {
  .\dist\log-reviewer-windows-amd64.exe fetch --host 192.168.1.20 --user logreader --path /var/log/myapp --fingerprint 'SHA256:<已核实的主机指纹>' --recursive --analyze
} finally {
  Remove-Item Env:LOG_REVIEWER_SFTP_PASSWORD -ErrorAction SilentlyContinue
}
```

默认从 `LOG_REVIEWER_SFTP_PASSWORD` 和 `LOG_REVIEWER_SFTP_PASSPHRASE` 读取密码与私钥口令。可用 `--password-env`、`--passphrase-env` 指定其他环境变量名。GUI 在当前页面内按服务器、端口和用户名记住已提交的密码，连接失败、修改路径或关闭并重新打开对话框后可直接重试；刷新或关闭页面后需重新输入。密码不会写入状态文件或浏览器存储。GUI 在请求被接受后清空私钥和私钥口令输入。凭据使用后依赖进程内存回收，不承诺内存的即时清零。

CLI 在 `out-dir` 下为每次操作创建独立 `sftp-*` 目录。不带 `--analyze` 时显式下载：先写 `.part`，完成校验后改名为 `.log`，`manifest.json` 保存来源和副本位置，下载失败或取消会清理本次目录。带 `--analyze` 时默认直接读取远程日志，只生成 `report.json` 和索引；发生网络读取错误才在该会话目录创建对应文件的缓存。分析失败可能保留会话目录，确认不再需要后可删除。

## 限制与来源追踪

- 默认最多 50 个文件，可调整至 10000；每次获取总大小最多 10 GiB。缓存可随多次获取累计，需留足磁盘空间。
- 默认不递归，递归最多 32 层，总扫描目录项最多 100000；用户明确填写的入口路径允许是符号链接，扫描目录时继续跳过子项中的符号链接。目录列表由组件先读取再检查数量，超大单目录仍有额外内存开销。
- 网络连接和 SSH 握手上限各 30 秒，传输期间无网络活动超过 30 秒会终止。持续有数据的大文件不受总时长 30 秒限制。可通过取消或 Ctrl+C/SIGTERM 主动终止。
- 下载以列目录时观察到的大小为界，不追逐持续增长的日志；文件截断则失败。下载后比较大小和修改时间，变化会记录警告及 changed=true。同大小同修改时间的改写或轮转无法可靠识别，因此不保证强一致快照。
- 报告 `sources[].remote` 与详情 `remote` 包含协议、服务器、端口、原始路径、获取时间、原始修改时间和变化标志。直读报告的 `source.size` 是分析时校验的远程文件大小；显式下载的 `manifest.json` 另记录副本位置。
- GUI 正常直读不创建日志副本；网络错误产生的副本及 manifest 存在会话缓存，可用 `--cache-dir` 调整位置，默认退出删除，`--keep-cache` 可保留。CLI 会话输出默认保留。单次缓存重试总时长上限为 5 分钟。
- 传输使用 SFTP 加密；浏览器向工具提交凭据的连接需另行保护。远程 GUI 优先用 HTTPS 或 SSH 隧道，普通 HTTP 会明文传输浏览器提交的认证信息。
- 无时区的日志时间仍按分析机器本地时区解析；多台服务器时区不同的日志应带明确时区，避免错误对齐事件。压缩日志不会自动解压，目录有 .gz 等文件时建议使用 `*.log,*.txt` 过滤。
- 连接由工具运行的机器发起，使用其网络；GUI 选择私钥文件来自浏览器所在机器。CLI 的 key、known-hosts 路径属于 CLI 所在机器。
- 当前同一实例只允许一个分析或远程获取任务。没有定时同步、断点续传、SSH agent、跳板机、ssh_config、任意远程命令或自动解压支持。

## 本版范围

仅支持 SSH 上的 SFTP 子系统。FTP/FTPS、vsftpd 服务端、旧 SCP 协议尚未支持；vsftpd 是 FTP/FTPS 服务端软件，并非独立协议。若服务器关闭 SFTP 子系统，联系管理员开启，或在服务器直接运行本工具，通过浏览器访问分析结果。

本版目标是可信人员的按需获取。后续按实际需要增加目录访问边界、独立会话、跳板机及轮转增量获取，不默认扩大认证与远程执行范围。
