# 界面统一与稳定性审查

日期：2026-10-15。范围：当前工作区的日志导入、内容呈现与查询、远程预览和下载、访问控制相关流程。

## 已修复

| 问题 | 处理 |
| --- | --- |
| 复选框尺寸、表单间距不一致 | 集中统一控件样式、禁用及焦点状态，远程表单使用语义化分区 |
| 关闭弹窗后提示随弹窗消失 | 提示转移到当前可见顶层，保留剩余显示时间 |
| 关闭远程窗口后凭据仍被保留 | 等待已发送请求结束后释放服务端预览，取消运行中任务，清空浏览器认证字段 |
| 旧请求在窗口关闭后更新界面 | 使用会话版本忽略旧响应，停止旧轮询 |
| 查询失败无限轮询 | 单次请求 30 秒超时，连续三次失败后恢复操作并提示重新连接 |
| 超长单行着色耗时过长 | 修正匹配边界，超长行回退原文，保留完整内容 |
| 复杂正则阻塞界面 | Worker 隔离执行、2 秒超时终止，继续复用 mark.js 标注结果 |
| 密集匹配生成过多标记 | 最多标注 2000 处，并在计数中显示上限标识 |
| 远程请求输入边界不完整 | 拒绝尾随 JSON、空白路径、NUL、超过 100 行或 64 KiB 的路径输入 |

不引入新的服务或运行时依赖。截图、测试证据及可执行文件存放临时目录，不纳入仓库。

## 部署适用范围

当前适合受控内网中的日志审查，使用 HTTPS、来源 IP 限制和会话 token。获得有效 token 的操作者能读取工具账户可访问的本地日志，也能发起远程获取；它不是具有用户隔离、角色权限和租户边界的公共 SaaS。

建议以专用低权限账户运行，日志只读授权；跨机器使用可信证书，并关闭不需要的 HTTP 入口。远程账户优先使用只读 SFTP 权限和私钥认证。主机指纹必须核实，认证秘密不写入状态文件。

本轮测试不能代替实际数据规模下的容量验收。Windows 本机 `-race` 测试进程退出码为 `0xc0000139`，未取得竞态检测结果；应在兼容的 Go/CGO 环境或 Linux CI 中补跑。
