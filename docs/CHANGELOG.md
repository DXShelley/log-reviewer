# 版本记录

## 1.0.0 · 2026-10-15

- 首个 1.x 大版本，整合近期日志工作区、统一 GUI 设置、本机/SFTP 只读分析、导入一致性和访问安全能力。
- 统一管理布局、上下文、文件格式、存储目录及访问控制；文件格式配置覆盖本机、上传和远程来源，支持已有缓存迁移。
- 本机路径和 SFTP 默认直读，支持多文件分类、全文搜索、上下文查看、时间窗口导出以及六种工作区布局。
- CLI、GUI 与 JSON 报告版本统一为 1.0.0；报告 schema 保持 `log-reviewer/v1`，沿用现有 CLI/API 参数及 `dev`/`main` 分支分工。

- 保留上传的本地副本，避免与远程直读去重后依赖网络；每批导入重新校验可变源摘要并保留别名，校验失败时弃用旧摘要。
- 远程重复连接更新认证配置并保持报告 reader 可迁移；来源标识纳入内容摘要，防止复用内容已变化的引用。

- 修复本机路径直读与远程直读绕过内容去重的问题，GUI 各导入入口统一按 SHA-256 比较当前列表的内容。
- 本机选择器与输入路径接入同名确认，支持默认/手动显示别名、列表替换及取消，源文件始终只读；增加校验取消、文件变化及跨入口浏览器回归。
- 修正远程保存目录、退出清理、保留原始文件名及页面内密码记忆的说明；明确完整内容校验的额外读取成本。

## 0.7.1 · 2026-10-15

- GUI 默认打开 HTTPS（8766），保留 HTTP（8765），支持 `--http=false`；自签名证书持久化并在新增访问地址或临近到期时更新，也可指定证书和私钥。
- 新增客户端单 IP/CIDR 白名单，CLI 和 GUI 可配置，状态文件保存并在重启时加载；完善 Bearer token 格式校验、GUI 验证入口和配置防误锁。
- 补齐严格证书信任、主机名、TLS 版本、双协议鉴权、HTTP 关闭与证书异常启动失败回归，并新增 [安全测试矩阵](security-testing.md)。

- 本机 Windows 导入使用系统选择器返回真实路径，直接只读分析；其他本机环境引导填写路径，远程浏览器保留上传流程。
- 输入路径兼容普通路径、单双引号、JSON 字符串、文件 URI 和 Windows UNC；已存在的方括号文件名优先按字面路径处理。
- GUI 远程获取及 CLI `fetch --analyze` 默认 SFTP 直读，详情、搜索和导出共用只读入口，仅网络错误触发本地缓存重试。
- 补充路径兼容、远程直读与缓存、错误拒绝、选择器访问控制测试和 [验收说明](readonly-testing.md)。

- 文件操作与分析按钮紧凑排列，日志筛选、时间导出分行展示。
- 移除“应用全部上下文”和“使用总体”；总体设置修改后自动生效，保留单条查询。
- 分析和导出显示遮罩，分析可取消，成功或失败自动关闭。
- 公开 GitHub 仓库，补齐文档导航、开发指南、贡献与安全报告、Issue/PR 模板及固定版本 CI。
- 构建脚本自动生成六平台 SHA256 校验列表并排除临时备份文件。

## 0.7.0 · 2026-10-14

- 用 frontend-design 技能调整功能分组和视觉层级，布局切换移到右上角。
- 离线打包 Highlight.js 精简核心与 Lucide 选定图标，日志级别、时间、ID、异常和堆栈位置着色；复制/导出保留原文。
- 自动上下文根据堆栈、异常提示、请求 ID、logger、线程和时间边界推断，完整事件不裁剪；单条手动覆盖仍优先。
- CLI 增加 `--auto-context`，HTTP 详情增加 `context=auto|manual` 与实际范围元数据。
- 内容工具栏增加自动换行，保留复制与原生全屏/弹框回退。

## 0.6.0 · 2026-10-14

- 六种工作区布局、移动端纵向降级、日志全屏。
- 默认折叠同类事件，摘要最多读取 4 KiB，展开后读取正文与上下文。
- 总体上下文应用全部分类，单条事件可覆盖或恢复总体。
- 多文件拖放反馈，GUI 时间片段合并/分文件 ZIP 导出，CLI `export-time`。
- `--ssh-dir` 与 GUI 目录设置自动读取 `known_hosts`，SSH 默认端口 22。

## 0.5.0 · 2026-10-14

- 新增内置 SFTP 获取单文件或目录，支持密码、普通私钥、加密私钥与主机密钥校验。
- GUI 支持目录过滤、递归、数量/总大小限额、进度、取消及获取后分析；请求接受后清空凭据。
- CLI 新增 fetch 命令，认证信息从私钥文件或环境变量读取；支持 --analyze。
- 下载临时文件完成后改名，失败/取消清理本次副本；保存无凭据 manifest，检测远程文件变化。
- 报告来源与详情增加可选 remote 元数据；构建最低 Go 版本升为 1.25。

## 0.4.0 · 2026-10-14

- 新增 `--host`，默认 `0.0.0.0`，尝试同端口 IPv6；端口不可用时自动分配。
- 输出最终本机 IPv4/IPv6 与网卡访问地址，提示 NAT 和防火墙可达性需要独立确认。
- 调整 Host/Origin 校验支持远程 IP 和显式域名白名单；API 仍要求 token。
- 新增 `--cache-dir`，支持 SIGTERM 清理；补充无 GUI 服务器、SSH 隧道和代理使用说明。

## 0.3.0 · 2026-10-14

- 识别规则改为独立语言列表，每种语言单独编辑与保存，切换时保留草稿。
- 支持恢复内置规则、新增和删除自定义语言；无效正则不覆盖原配置。
- 按语言持久保存配置，GUI 和 CLI 自动加载，下次分析生效。
- 新增语言规则管理 API 及桌面、移动端端到端验证。

## 0.2.2 · 2026-10-14

- 时间筛选结束值包含所选秒、分钟或日期内的全部日志，显式小数精度保持精确边界；GUI 传递带时区的时间。
- 日期时间使用独立日历弹窗，修改后通过“确认”提交，“取消”不改变原值。
- 关键字、正则、时间与文件范围支持独立重置，并保留全部重置。
- 新增粘贴 UTF-8 日志文本入口，可与选择、批量导入的多个文件一起分析。
- 批量导入期间禁止启动分析；已成功导入的文件立即显示，允许重复选择同一文件。
- 重新分析时清空旧结果，忽略旧状态请求，并暂停旧报告查询，避免刷新打断分类选择。

## 0.2.1 · 2026-10-14

- 关键字或正则搜索的上下文围绕首次匹配所在行展示；无文本条件时围绕完整事件。
- GUI、CLI 和 API 同步提供参数；修复旧上下文只读取 4096 字节导致行数不足的问题。
- 增加参数、边界、空行和关键字定位测试；GUI 验证默认值及修改后重新加载。
