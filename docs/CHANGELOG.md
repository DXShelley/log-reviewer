# 版本记录

## 0.2.1 · 2026-10-14

- 上下文可分别配置前后行数，默认前 20 行、后 100 行，范围 0–10000。
- 关键字或正则搜索的上下文围绕首次匹配所在行展示；无文本条件时围绕完整事件。
- GUI、CLI 和 API 同步提供参数；修复旧上下文只读取 4096 字节导致行数不足的问题。
- 增加参数、边界、空行和关键字定位测试；GUI 验证默认值及修改后重新加载。

## 0.2.0 · 2026-10-14

- 内置 17 种独立语言规则，按事件证据自动识别一个或多个语言。
- 分类、文件和 Agent JSON 报告提供语言信息，GUI 分类显示语言。
- 支持导出规则、外部 JSON 覆盖某种语言与添加新语言；GUI/API 支持语言规则数组。
- 增加裸异常收集、Python/PHP 警告识别与 Python 链式异常根因提取。
- 单元测试、GUI 回归与六平台构建通过；1GiB 混合 2.741 秒、全 ERROR 8.305 秒；10GiB 混合 27.179 秒。

## 0.1.0 · 2026-10-14

- 单文件二进制，提供 terminal 与本机浏览器 GUI。
- 流式多文件扫描、固定长度磁盘索引、Java / Python 多行异常识别。
- 通用文本、JSON、Pino、Serilog、glog、Go panic 及自定义规则。
- 异常指纹聚合，次数、首尾时间、启发式影响、可观察来源范围。
- 时间、关键字、逐行正则、级别和文件筛选；分页详情、上下文、复制与导出。
- Agent JSON stdout、schema 报告、稳定分类 ID、样本字节位置与认证 HTTP API。
- Windows amd64 实测；另外五个平台完成编译。

已知边界与测试限制见 `VALIDATION.md`，包括 clipboard、race、平台实际运行及性能适用范围。
