# v0.2.0 验证记录

新增 17 种语言证据正例、含糊信息负例、混合文件、覆盖与新增语言规则、无效正则、裸 JavaScript 堆栈、Python/PHP 警告、Python 链式异常根因测试。原有扫描、分类、查询、导出、服务测试继续通过。

六平台交叉编译通过；二进制大小约 5.9–6.5MiB。Windows 实际执行，其他平台未在真实系统运行。

GUI Playwright 验证通过，包含文件选择、多文件、Java 堆栈、上下文、复制、导出、搜索、上传与桌面/手机布局。本轮系统剪贴板实际读回 840 个字符。

大文件测试采用原有重复模板与热缓存样本。最终构建复测：1GiB 混合日志 2.741 秒、1GiB 全 ERROR 日志 8.305 秒。指标保存在本项目 reports/bench-language-*.json。数据不保证任意机器、任意格式达到相同耗时。

10GiB 混合日志完整扫描：27.179 秒，7,699,835 个事件，2 个分类；索引使用磁盘保存。

规则由用户提供的外部 JSON 保存；GUI 当前提供 JSON 编辑。自动语言识别以已收集事件的前 64KiB 为依据，证据不足时显示“语言未知”。规则为启发式，不能覆盖所有框架或所有输出格式。
