# 工作区与时间片段导出

## 文件与布局

可将多个文件拖入窗口，释放后逐个导入；也可选择本机路径、导入文件、粘贴文本或获取 SFTP 文件。浏览器导入会复制文件到工具缓存，大文件位于工具机器时优先“选择文件”。正在分析或导入期间不接受新拖放。

| 布局 | 内容 |
| --- | --- |
| 左右 | 分类与事件详情，正文显示在展开事件下 |
| 上下 | 分类在上，详情在下 |
| 上中下 | 分类、事件列表、选中内容纵向排列 |
| 左中右 | 分类、事件列表、选中内容横向排列 |
| 上左右 | 上方分类，下方事件列表和内容 |
| 详情弹框 | 分类与摘要，点击事件后弹框显示内容 |

小屏幕自动纵向排列。布局保存在当前浏览器。点击单条事件的 `⛶` 全屏浏览，可通过 Esc 退出。

## 事件与上下文

摘要显示文件名、起始行、日志时间和前 4 KiB 中找到的 `requestId`、`traceId`、`correlationId`；没有这些 ID 时用字节位置定位，不表示业务 ID。时间未知会明确标注。点击后才读取正文和上下文。

总体默认前 20、后 100 行，修改后点“应用全部上下文”，所有分类生效并清除单条覆盖。“恢复 20 / 100”恢复默认值。单条事件的前后行数修改后点“查询”，“使用总体”取消覆盖。单条覆盖只在本次页面会话中保留，总体设置保存在浏览器。

关键字/正则查询时上下文围绕首次匹配行，另附完整事件以保留堆栈。无文本条件时围绕完整事件。正文及各方向上下文有 2 MiB 显示上限，完整内容可导出。

## 时间片段

GUI 先分析文件，选开始/结束时间，再选“时间片段 · 合并”或“时间片段 · 分文件 ZIP”，点击“导出时间片段”。使用时间和文件范围条件，忽略关键字、正则、分类、级别过滤；未勾选 INFO 也能导出普通日志。

```sh
log-reviewer export-time --report report.json --from '2026-10-14T12:30:00+08:00' --to '2026-10-14T12:35:00+08:00' --out nodes.txt
log-reviewer export-time --report report.json --from '2026-10-14T12:30:00+08:00' --to '2026-10-14T12:35:00+08:00' --out-dir nodes-period
```

`--source N` 指定零基文件索引。CLI 输出文件/目录必须不存在，避免覆盖日志。分文件名为 `序号-日志文件-开始时间-结束时间.log`，非法字符替换为 `_`，序号避免多节点同名冲突。

按报告 `sources` 顺序合并，不按跨节点时间重排。合并保留原始字节，仅在文件边界缺少换行时补换行；分文件原样保留。无时间续行继承前一条可识别时间，因此包含堆栈；文件开头的无时间内容排除。无时间独立日志也会继承前一时间，这是缺少时间信息时的限制。可处理时间乱序。扫描使用内置格式，不继承分析时临时传入的自定义日志头规则；无法识别的特殊时间格式需先转换。

结束秒、分钟、日期包含整个精度范围，显式小数按精确边界。GUI 使用浏览器时区，CLI 无时区时间使用工具机器时区，多节点建议显式写时区。导出重新流式扫描并校验快照；源日志追加、轮转或替换后应重新分析。缓存磁盘需容纳临时导出和 ZIP。

Chrome / Edge 可流式保存大文件；其他浏览器超过 256 MiB 时请使用 CLI。

## SSH 信任目录

```sh
log-reviewer fetch --host 192.168.1.20 --user deploy --path /var/log/app --ssh-dir /home/deploy/.ssh --key /home/deploy/.ssh/id_ed25519 --analyze
```

SSH 端口默认 22。未指定指纹或 `--known-hosts` 时读取指定目录的 `known_hosts`，未指定目录则使用运行账户的 `~/.ssh/known_hosts`。GUI 路径指向**工具所在机器**，不是访问网页的电脑。

保留 OpenSSH 的端口匹配、散列主机与密钥校验；文件缺失、密钥不匹配、未知主机均拒绝连接。指定目录不自动读取私钥或 SSH config，认证私钥仍由 `--key` 或 GUI 提供。不自动信任未知主机。
