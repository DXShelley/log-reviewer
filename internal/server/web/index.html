输入路径的用途与示例

读取运行 Log Reviewer 的机器上的文件，不经浏览器上传。适合已在该机器上的大日志、固定日志目录或批量日志。若浏览器与工具不在同一台机器，这里填写工具所在机器的路径；其他服务器的文件请使用“远程获取”。

每行一条，可填文件、目录或通配符。Windows 示例：C:\logs\app.log、C:\logs\*.log；Linux 示例：/var/log/myapp、/var/log/myapp/*.log。优先使用绝对路径；相对路径以工具启动目录为基准。

目录按“文件设置”识别当前层文件，不递归子目录。通配符支持 *、? 和字符集合，不支持 ** 递归。点击“添加路径”后，再点击“开始分析”；源文件只读。

路径与过滤
过滤规则与示例

每行一条，文件名规则任一匹配即获取。选择单个文件时不使用过滤。普通规则用通配符，正则规则以 regex: 开头。

*.log
全部 .log 文件
app-*.log
app- 开头的日志
regex:^app-\d{4}-\d{2}-\d{2}\.log$
日期日志，如 app-2026-10-15.log
regex:(?i)\.(log|txt)$
.log 或 .txt 后缀，忽略大小写
exclude-dir:backup
忽略各层级中名为 backup 的目录及其全部内容
exclude-dir:cache*
忽略 cache、cache-1 等目录及其全部内容

忽略目录规则以 exclude-dir: 开头，每行一个目录名通配符，不填写路径；开启“包含子目录”时生效，不排除明确选择的入口目录。可与 *.log 等文件名规则一起使用。

正则支持 ^ 开头、$ 结尾、\d 数字、| 或、(?i) 忽略大小写；. 匹配任意字符，文件名中的句点需写成 \.。不支持前后查找或反向引用。兼容原有逗号分隔的通配符；正则中的逗号按原样处理。
